## Purpose

Create a distinct four-slide Instagram carousel that explains how the printed page records a Pen Pad Golf round. ## Instagram-ready caption

The page keeps the score. ⛳

Start in the tee box, stand the pen upright, and flick toward the hole. Wherever the pen lands, mark the spot as one stroke. Stand it at the new mark and flick again. Keep going to the flag, then count the marks. Lowest score wins.

Save the page scorecard and see how to play. Pen Pad Golf is in development.

## Slide copy

1. The page keeps the score. Each landing leaves a mark. Each mark records one stroke.
2. Stroke one starts here. Stand the pen upright in the tee box. Flick toward the hole.
3. Mark every landing. Wherever the pen lands, mark the spot as one stroke. Stand at the mark and flick again.
4. Count the marks at the flag. Each landing is one stroke. Lowest score wins.

CTA: Save the scorecard and see how to play.
